개인정보처리방침

시행일: 2026년 10월 26일

1. 계산용 생년월일

입력한 생년월일은 브라우저 안에서 만 나이와 연령 조건을 계산하는 데 사용합니다. 계산기 코드에서는 서버 전송, URL 기록, 쿠키 또는 localStorage 저장을 하지 않습니다. 새로고침하거나 페이지를 닫으면 입력 상태는 유지하지 않습니다.

2. 화면 테마 저장

사용자가 선택한 밝은 화면·어두운 화면 설정은 브라우저 localStorage의 workingholidayage-theme 항목에 저장합니다. 생년월일과 연결하지 않으며 서버로 전송하지 않습니다. 해당 사이트의 브라우저 데이터를 삭제하면 설정도 지울 수 있습니다. 저장된 설정이 없으면 기기의 화면 설정을 따릅니다.

3. 접속과 외부 리소스

이 사이트는 Cloudflare Pages로 제공합니다. Cloudflare는 페이지 전달, 보안 및 서비스 운영 과정에서 IP 주소, 요청 시각, URL, 브라우저 정보 등의 접속 정보를 처리할 수 있습니다. 해당 정보의 처리와 보관은 서비스 설정 및 Cloudflare 개인정보처리방침에 따릅니다. 국기 이미지는 flagcdn.com 및 whic.mofa.go.kr에서 불러오며, 이미지 요청 시 해당 제공자에게 IP 주소와 요청 정보가 전달될 수 있습니다.

외부 블로그·공식 기관 링크를 누르면 다른 사이트로 이동하며 해당 사이트의 개인정보처리방침이 적용됩니다. 외부 링크에는 사이트 정보 전송을 줄이기 위한 noreferrer 설정을 사용합니다.

4. Google Analytics 방문 통계

서비스 이용 현황을 이해하고 사용성을 개선하기 위해 Google Analytics 4(측정 ID: G-8QRH9FPYYT)를 사용합니다. Google 태그는 방문한 페이지, 기기·브라우저 정보, 방문 경로와 사이트 이용 이벤트 등을 처리하며 쿠키 등 식별자를 사용할 수 있습니다. 계산기에 입력한 생년월일 자체를 분석 이벤트나 사용자 속성으로 설정하지 않습니다.

데이터의 처리와 보관은 Google Analytics 속성 설정 및 Google 정책에 따릅니다. 브라우저에서 쿠키를 차단·삭제하거나 Google Analytics 차단 부가기능을 이용해 측정을 관리할 수 있습니다. Google의 파트너 사이트 데이터 사용 안내에서 자세한 내용을 확인하세요.

5. Google 광고와 쿠키

현재 계산기 페이지에는 Google 광고를 요청하는 스크립트가 없습니다. 계정 확인용 메타 태그와 ads.txt는 광고를 표시하거나 쿠키를 설치하는 코드가 아닙니다.

Google 광고를 도입하는 경우 Google 및 제3자 공급업체는 이 사이트 또는 다른 사이트의 이전 방문 기록에 따라 광고를 제공하기 위해 쿠키를 사용할 수 있습니다. Google 광고 쿠키는 Google과 파트너가 인터넷상의 방문 기록을 바탕으로 광고를 제공하도록 합니다. 광고 도입 시 실제 공급업체·동의 설정에 맞춰 이 방침을 갱신합니다.

Google 광고 설정에서 개인 맞춤 광고를 관리하거나 거부할 수 있습니다. 다른 공급업체의 설정은 제3자 광고 선택 도구에서도 확인할 수 있습니다. Google의 파트너 사이트 데이터 사용 안내도 참고하세요.

6. 문의 정보의 처리

사이트 소스는 GitHub 계정 leega670-cmd가 관리하며, GitHub 이슈로 오류와 정정 요청을 받습니다. 이 사이트는 별도 문의 입력 양식이나 문의 데이터베이스를 운영하지 않습니다. 이슈에 작성한 GitHub 계정명, 본문, 첨부물 등은 GitHub에서 처리하고 공개하며, 사이트 관리자는 문제 확인과 답변을 위해 내용을 열람합니다.

개인정보를 게시하지 마세요. 이슈 내용은 작성자 또는 관리자가 삭제하기 전까지 공개될 수 있으며, GitHub의 보관·삭제 규정이 적용됩니다. 삭제 요청은 개인정보를 다시 적지 않고 해당 이슈 주소만 알려주세요. 자세한 계정 정보 처리와 권리 행사 방법은 GitHub 개인정보처리방침에서 확인할 수 있습니다.

7. 문의와 방침 변경

개인정보 관련 문의와 정정 요청은 문의 안내를 참고하세요. 광고·분석 도구 또는 데이터 처리 방식이 바뀌면 이 페이지의 내용과 날짜를 갱신합니다.
